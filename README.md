# 深夜三時のレジ

深夜のコンビニで、前任者が残した手書きのマニュアルだけを頼りに、来た客が人間かどうかを見分けるルール系ホラーゲームです。来る客の顔ぶれと順番は毎晩変わります。

**遊ぶ：** https://yadonn-code.github.io/shinya-register/

- PC版：https://yadonn-code.github.io/shinya-register/pc/
- スマホ版：https://yadonn-code.github.io/shinya-register/sp/

音が出ます。ヘッドホン推奨。

## 遊び方

午前0時から6時まで、来た客ごとに「接客する」か「目を伏せる」かを決めます。

- 人間を無視すると苦情が入ります。3件で解雇です。
- 人間ではないものに接客すると、あなたの影が減ります。3つなくなるとアウトです。

見分ける手がかりは、マニュアルのルール、チャイムの音、足元の影、防犯カメラの映像、顔のアップ、そして会話です。

- 見た目はいかにも幽霊なのに、ルールはすべて満たしている人間が来ます。追い返すと苦情になります。
- 見た目も話し方も普通なのに、ルールを一つだけ黙って破っているものも来ます。ドアは開くのにチャイムが鳴らない、ということもあります。
- 「話しかける」で、どこから来たかを二回聞けます。人間は同じ答えを返し、人でないものは答えが変わります（酔っぱらいと寝ぼけた人は別）。
- 顔・足元・カメラを見ると、客が気づいて何か言うことがあります。
- 結果画面で、見誤った相手の正体がわかります。

## 操作

| 操作 | PC版 | スマホ版 |
|---|---|---|
| 接客する | `1` | 画面下のボタン |
| 目を伏せる | `2` | 画面下のボタン |
| 顔を見る | `V` | 画面下のボタン |
| 足元を見る | `F` | 画面下のボタン |
| 防犯カメラ | `C` | 画面下のボタン |
| 話しかける | `T` | 画面下のボタン |
| マニュアル | `M` | 画面下のボタン |
| 次へ | `Enter` | 画面下のボタン |
| エンディングを飛ばす | `Enter` / クリック | 画面をタップ |

PC版には全画面ボタンがあります。スマホ版は、驚かしのときに端末が振動し（Android）、プレイ中は画面が消えません。ブラウザの「ホーム画面に追加」で、アプリのように起動できます。

## ファイル構成

ビルドは不要です。HTML・CSS・JavaScriptだけで動きます。

```
index.html            入口（端末に合わせてPC版かスマホ版をおすすめする）
pc/index.html         PC版
sp/index.html         スマホ版
sp/manifest.webmanifest  スマホでホーム画面に追加するための設定
game.js               ゲーム本体（PC版とスマホ版で共通）
game.css              共通の見た目
pc.css / sp.css       PC版・スマホ版それぞれのレイアウト調整
icon.svg / icon-*.png アイコン
```

客の名簿は `game.js` の `POOL`（幽霊に見える人間は `POOL.seemGhost`、普通に見える人でないものは `POOL.stealth`）、会話は `TALK`、一夜の組み立ては `buildNight()` にあります。手元で試すときは `index.html` をブラウザで開いてください。
