# 深夜三時のレジ

深夜のコンビニで、前任者が残した手書きのマニュアルだけを頼りに、来た客が人間かどうかを見分けるルール系ホラーゲームです。来る客の顔ぶれと順番は毎晩変わります。

**遊ぶ：** https://yadonn-code.github.io/shinya-register/

- PC版：https://yadonn-code.github.io/shinya-register/pc/
- スマホ版：https://yadonn-code.github.io/shinya-register/sp/

音が出ます。ヘッドホン推奨。

## 遊び方

夜勤は三日間です。毎晩、午前0時から6時まで、来た客ごとに「接客する」か「目を伏せる」かを決めます。

- 人間を無視すると苦情が入ります。3件で解雇です。
- 人間ではないものに接客すると、あなたの影が減ります。3つなくなるとアウトです。

見分ける手がかりは、マニュアルのルール、チャイムの音、足元の影、防犯カメラの映像、顔のアップ、そして会話です。

- 見た目はいかにも幽霊なのに、ルールはすべて満たしている人間が来ます。追い返すと苦情になります。
- 見た目も話し方も普通なのに、ルールを一つだけ黙って破っているものも来ます。ドアは開くのにチャイムが鳴らない、ということもあります。
- 「話しかける」で、どこから来たかを二回聞けます。人間は同じ答えを返し、人でないものは答えが変わります（酔っぱらいと寝ぼけた人は別）。
- 顔・足元・カメラを見ると、客が気づいて何か言うことがあります。
- 結果画面で、見誤った相手の正体がわかります。

### 三日間の夜勤

- **前の夜の判断が返ってくる**：追い返した人間は翌日文句を言いに来て、本部から苦情の電話も入ります。接客してしまった人でないものは「常連」になって戻り、昨夜とは別のところでぼろを出します。夜を越えると、影は元に戻ります。
- **難易度**：タイトルでノーマルかハードを選べます。

  | | ノーマル | ハード |
  |---|---|---|
  | 夜を越えたとき | 影が元に戻り、苦情が一件減る | 影は戻るが、苦情は減らない |
  | 考える時間 | ふつう（話しかけると少し延びる） | 7割、話しかけても延びない |
  | 本部の電話 | このあと来るものの特徴を教えてくれる | ヒントなし |
  | 店内の異変 | 4組放っておくと近づいてくる | 3組で近づいてくる |
  | 見間違いの報告 | 2回で苦情 | 1回で苦情 |
  | 客の反応（手がかり） | ふつう | 半分 |
  | 限定の客 | なし | 1晩に1人ずつ（下記） |

  ハード限定の客：身分証の生年月日が「2月30日」の几帳面そうな女、チャイム・影・カメラ・身分証がすべて正常で、話しかけたときの答えの変化と瞳でしか見分けられない感じのいい青年、三日目の白無垢の花嫁（影がなく、見誤るとその場でゲームオーバー。予告なし）。ふつうの顔ぶれと順番は変えずに、あいだへ差しこまれます。
- **午前4時台**：有線から、ベートーヴェン「運命」の冒頭がピアノで繰り返し流れます（パブリックドメイン）。音楽家の客が来て曲が鳴るあいだは止まります。
- **書き換えられるマニュアル**：午前3時になると、毎晩だれかが黒以外のインクでルールを書き足します（一日目は赤、二日目は青、三日目は佐藤さんの行が赤く書き換えられる）。
- **年齢確認**：お酒やたばこを買う客は身分証を出します。写真・生年月日・名前・有効期限のどれかがおかしければ人でないもの。本物の身分証で十七歳なら、未成年なので売ってはいけません。
- **2人連れ**：1人目の会計のあいだ、もう1人は後ろで待っています。チャイムが1回しか鳴らなかったら、どちらかがおかしい。
- **店内の異変**（二日目から）：看板・冷蔵ケース・棚・床・蛍光灯のどこかが変わります。［異変を報告］で元に戻ります。放っておくと近づいてきます。見間違いの報告が続くと苦情になります。
- **本部の電話**：本部はこのあと来る人でないものの特徴を教えてくれます。番号が一桁違う「本部」は偽物で、嘘を言います。
- **前任者の謎**：日誌の切れ端を4枚集めると、三日目の朝に隠しエンドへの道が開きます。
- **音楽家**：燕尾服のピアニスト（ショパンの葬送行進曲）、弦のないヴァイオリンの女、ゼンマイが切れかけたオルゴールを抱いた男の子が来ます。バッハを口ずさむチェロケースの音大生は人間です。曲はパブリックドメインのクラシックかオリジナルで、その場で合成しています。
- **見誤ったら終わりの客**：二日目と三日目に一人ずつ来ます。接客すると「終演」になる白髪の指揮者（人間ではない）と、追い返すと「監査不合格」になる本部の監査員（人間）。ノーマルでは「ここで間違えたら終わりだ」という予感と速い心音で知らせますが、ハードでは知らせません。
- **悲鳴**：人間でないものに接客すると、すぐ近くで悲鳴が上がります。人間を追い返すと、店を出たあとに駐車場のほうから悲鳴が聞こえます。

### 図鑑と夜の番号

- タイトルの［客の図鑑］に、見抜いた客・見たエンディング・集めた切れ端が記録されます（この端末のブラウザに保存）。
- タイトルで「夜の番号」を入れるか、`?n=12345` のようなURLを開くと、同じ番号の人は同じ顔ぶれの夜を遊べます（`&d=hard` を付けるとハードで始まります）。結果画面の［結果をシェア］で、番号付きのURLを送れます。

## 操作

| 操作 | PC版 | スマホ版 |
|---|---|---|
| 接客する | `1` | 画面下のボタン |
| 目を伏せる | `2` | 画面下のボタン |
| 顔を見る | `V` | 画面下のボタン |
| 足元を見る | `F` | 画面下のボタン |
| 防犯カメラ | `C` | 画面下のボタン |
| 身分証 | `I` | 画面下のボタン |
| 話しかける | `T` | 画面下のボタン |
| 異変を報告（二日目から） | `R` | 画面下のボタン |
| マニュアル | `M` | 画面下のボタン |
| 次へ | `Enter` | 画面下のボタン |
| エンディングを飛ばす | `Enter` / クリック | 画面をタップ |

PC版には全画面ボタンがあります。スマホ版は、驚かしのときに端末が振動し（Android）、プレイ中は画面が消えません。ブラウザの「ホーム画面に追加」で、アプリのように起動できます。

## ファイル構成

ビルドは不要です。HTML・CSS・JavaScriptだけで動きます。

```
index.html            入口（端末に合わせてPC版かスマホ版をおすすめする）
pc/index.html         PC版
sp/index.html         スマホ版
sp/manifest.webmanifest  スマホでホーム画面に追加するための設定
game.js               ゲーム本体（PC版とスマホ版で共通）
game.css              共通の見た目
pc.css / sp.css       PC版・スマホ版それぞれのレイアウト調整
icon.svg / icon-*.png アイコン
```

客の名簿は `game.js` の `POOL`（幽霊に見える人間は `seemGhost`、普通に見える人でないものは `stealth`、未成年は `minor`、身分証がおかしいものは `idFake`、2人連れは `pair`）、会話は `TALK`、マニュアルは `RULES` と `FORGED`、一夜の組み立ては `buildNight(夜, 前の夜の判断)` にあります。手元で試すときは `index.html` をブラウザで開いてください。
